SigmaOS — Sovereign Linux Desktop
================================================================================

Welcome to SigmaOS, a modular, security-hardened Linux distribution.

SigmaOS Features
================================================================================

Security:
  • AppArmor ENABLED by default with enforcement mode
  • Kernel hardening via sysctl (ASLR, ptrace restrictions, network hardening)
  • Auditd pre-installed for security event logging
  • Secure Boot signing tools included (sbctl, tpm2-tools)
  • Automatic security updates via systemd timer

UX/VM Experience:
  • Software-rendering fallbacks enabled (pixman, llvmpipe) — works in VMs
    providing better Wayland rendering in virtual environments
  • Better Wayland support out of the box with full PipeWire stack

Desktop:
  • Hyprland + Waybar + Quickshell pre-configured with modern defaults
  • Better theme system (SigmaOS Theme Registry) with dynamic switching
  • Integrated installer (sigmaos-install) with BTRFS snapshots support

System Recovery:
  • Automatic BTRFS snapshots before/after pacman transactions
  • Easy rollback via sigmaos-snapshot rollback <snapshot>

Shortcuts (Hyprland)
================================================================================
  SUPER + Q        Close window
  SUPER + D        Launcher (Rofi)
  SUPER + Enter    Terminal (foot)
  SUPER + Shift + Q  Kill window
  SUPER + W        Toggle floating
  SUPER + [1-9]    Switch workspace
  SUPER + Shift + [1-9]  Move to workspace
  SUPER + F        Toggle fullscreen

Useful Commands
================================================================================
  sigmaos-doctor          Check system health
  sigmaos-theme-picker    Switch themes
  sigmaos-snapshot        Create BTRFS snapshot
  sigmaos-update          System update
  aa-status               Check AppArmor status
  sudo sigmaos-install    Install SigmaOS to disk
